# @gaozh1024/aliyun-speech 0.2.0 Release Notes

`0.2.0` updates Aliyun Speech for the Expo SDK 55 framework baseline while preserving Expo SDK 54 compatibility.

## Changes

- Peer dependencies now cover Expo `>=54 <56` and React Native `>=0.81 <0.84`.
- Development dependencies move to Expo SDK 55, React `19.2.0`, and React Native `0.83.6`.
- Expo audio dependencies are aligned with the SDK 55 package line for local package validation.

## Compatibility

Expo SDK 54 projects can stay on their SDK 54 native dependency versions and upgrade this package line. Expo SDK 55 projects should use Expo-managed install commands for native dependencies.
