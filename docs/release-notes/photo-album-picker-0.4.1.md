# @gaozh1024/photo-album-picker 0.4.1 Release Notes

`0.4.1` packages the current album-picker selection and video-preview improvements as a patch release.

## Changes

- Add configurable album toolbar colors and visibility controls for cancel and complete actions.
- Improve selected-count and preview navigation styling.
- Add video preview playback support while preserving the existing image preview and crop flow.
- Keep Expo SDK 54 and SDK 55 compatibility guidance unchanged.

## Upgrade

```bash
pnpm add @gaozh1024/photo-album-picker@^0.4.1
npx expo install --check
```
